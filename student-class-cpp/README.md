# Student Class in C++

This project demonstrates basic Object-Oriented Programming concepts in C++ using a `Student` class.

## Concepts Used
- Classes and Objects
- Private and Public Access Specifiers
- Getter and Setter Functions
- Stringstream
- Encapsulation

## Features
The `Student` class stores:
- Age
- First Name
- Last Name
- Standard

It also includes:
- Getter functions
- Setter functions
- `to_string()` method
